# NODEBETA AI — Deep Reasoning Engine Landing Page

A futuristic, minimal, and high-performance landing page for **NODEBETA AI**, positioned as the world's most powerful deep-reasoning AI. Built with modern web technologies for a cinematic, Apple/OpenAI-level user experience.

## ✨ Features

- **Cinematic hero** with animated neural network background (canvas)
- **Glassmorphism design** with subtle grain texture and depth effects
- **Smooth micro-interactions** powered by Framer Motion
- **Animated benchmark counters** and progress bars
- **Responsive layout** for mobile, tablet, and desktop
- **Accessible** and performance-optimized
- **Typographic excellence** with tight letter spacing and hierarchy

## 🛠️ Tech Stack

- **Next.js 14** (App Router)
- **React 18** + **TypeScript**
- **Tailwind CSS** (custom theme)
- **Framer Motion** for animations
- **Lucide React** for icons
